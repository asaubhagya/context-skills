## Decisions and deviations

| # | decision | why |
|---|---|---|
| 1 | Render path = HTML → headless Chrome (system Google Chrome 152), no Higgsfield/Canva | decision record row 21; the house style is vector/outline and the render is byte-deterministic; no key |
| 2 | Chrome gets a throwaway `--user-data-dir` + `--no-sandbox`, its output goes to a log file, and the script polls for Chrome's own "bytes written to file" line then stops the process | observed on this Mac: a fresh profile without `--no-sandbox` hangs; output to `/dev/null` hangs; after writing the PNG Chrome often never exits. The owner's one-liner (default profile, `--virtual-time-budget`) works only while no GUI Chrome holds the profile |
| 3 | Slide PNGs reach the Context issue through the Artifact Transfer (`create_artifact_upload` + curl with the Context Access Key by name), not `send_file` base64 | 8 × ~100 KB of base64 through the model per carousel is not viable for a nightly routine; the transfer is the server's own recommendation for binaries. Fallback stays: cover-only `send_file` + asset URLs |
| 4 | `postiz.sh` is the only Postiz caller and lives in the skill (not the host repo) | the key is read by name inside the script (env, else vault), so no `curl -H "Authorization: …"` ever appears in an agent transcript; the host repo only allow-lists the script path |
| 5 | Publisher records `Scheduled:` first and `Published:` on a later run | the Instagram permalink exists only after Postiz publishes; the daily brief and the dedupe guard read both |
| 6 | Blog MCP `publish` refused for a `draft` instagram post → "Publish record pending" comment, Postiz schedule kept | `blog-1.2.0` has no `instagram_post_set_status`; the owner's approval is in Context, the audit row waits for the server slice (flagged to the primary agent) |
| 7 | Instagram runs inside the existing drafter/publisher routines, no third and fourth launchd job | the E6 prompts already scope by channel; one lock, one log, one brief line per routine |
| 8 | Caption says "The full walkthrough is on the blog" although MTLY-177 (blog) is due Mon 22:00 SGT, 13 h after the IG slot (Mon 09:00 SGT) | the source topic is the blog piece and the issue's slot is fixed by the map; the owner can pull the blog slot forward or accept the lag at the gate |
